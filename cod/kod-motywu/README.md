# Wybrane fragmenty kodu motywu Centrum Odkrywania Doskonałości

To nie jest cały motyw, tylko wybrane pliki, które najlepiej pokazują, jak powstawał kod. Pełny motyw nie jest publikowany, bo prawa do niego, do treści i do zdjęć należą do Centrum Odkrywania Doskonałości. Kod jest pokazany wyłącznie do wglądu (zobacz [LICENSE](../../LICENSE)) i nie zawiera kluczy, tokenów, adresów CRM ani identyfikatorów pomiaru.

Opis projektu i mojego udziału: [README projektu](../README.md).

| Plik | Co pokazuje |
|---|---|
| [`inc/offers.php`](inc/offers.php) | Dane usług (typ wpisu „Oferta”) dla kart, zakładek, kreatora „Od czego zacząć?” i panelu ze szczegółami. |
| [`template-parts/cards/offer-card.php`](template-parts/cards/offer-card.php) | Kafelek usługi: etykieta, tytuł, krótki opis i cena. |
| [`inc/sections.php`](inc/sections.php) | Zgodność wstecz: sekcje stron z poprzedniego motywu (pola ACF) wyświetlane w nowym wyglądzie bez przepisywania treści. |
| [`inc/tracking.php`](inc/tracking.php) | Pomiar przez Google Tag Manager z Consent Mode v2. |
| [`assets/js/main.js`](assets/js/main.js) | Skrypty strony bez jQuery: kreator usług, zakładki oferty, okna ze szczegółami, mapa po kliknięciu, status godzin kontaktu, zdarzenia pomiaru i pilnowanie czytelnego kontrastu tekstu. |
