# Portal leczenia AZS – projekt treningowy

Ćwiczenie z kodowania stron: serwis o refundowanym leczeniu atopowego zapalenia skóry, zakodowana w HTML, CSS i JavaScript na podstawie **profesjonalnego projektu graficznego agencji Ajmer**. Projekt graficzny, treści i zdjęcia nie są moje – moja praca to przeniesienie projektu na działający, responsywny kod.

Autor kodu: Mateusz Dams · [portfolio](https://mateusz-dams.github.io/)

## Zakres ćwiczenia

- **Zakodowane podstrony:** strona główna, wprowadzenie, leczenie AZS (artykuł), baza specjalistów, baza ekspertów, aktualności, wpis, wydarzenia, wydarzenie, strefa dla lekarzy, kontakt, rejestracja, zmiana danych – 13 podstron.
- **Co działa:** menu mobilne, przejścia między wszystkimi zakodowanymi podstronami, wygląd formularzy rejestracji i zmiany danych.
- **Poza zakresem ćwiczenia:** wysyłka formularzy, wyszukiwanie, logowanie, przełącznik języka i podstrony, których nie było w projekcie. Po kliknięciu takiego elementu strona pokazuje krótki komunikat, a formularze działają w trybie pokazowym i niczego nie wysyłają.

Kopia ma znacznik `noindex`, żeby nie pojawiała się w wyszukiwarce obok strony firmy.

## Technologie

HTML · CSS (bez frameworka) · JavaScript
