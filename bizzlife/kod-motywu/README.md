# Wybrane fragmenty kodu motywu Bizzlife

To nie jest cały motyw, tylko wybrane pliki, które najlepiej pokazują, jak powstawał kod. Pełny motyw nie jest publikowany, bo prawa do niego, do treści i do zdjęć należą do biura rachunkowego Bizzlife. Kod jest pokazany wyłącznie do wglądu (zobacz [LICENSE](../../LICENSE)) i nie zawiera kluczy, tokenów, adresów CRM ani identyfikatorów pomiaru.

Opis projektu i mojego udziału: [README projektu](../README.md).

| Plik | Co pokazuje |
|---|---|
| [`inc/post-types.php`](inc/post-types.php) | Własne typy treści: Usługi i FAQ z tematami. |
| [`inc/meta-boxes.php`](inc/meta-boxes.php) | Dodatkowe pola usług i pytań (np. „Zakres usługi”, „Dla kogo”) bez wtyczek, na natywnych meta boxach WordPressa. |
| [`single-bzl_service.php`](single-bzl_service.php) | Szablon podstrony usługi. |
| [`inc/customizer.php`](inc/customizer.php) | Ustawienia motywu w panelu Dostosuj: teksty, zdjęcia, kolejność i tło sekcji strony głównej. |
| [`inc/seo.php`](inc/seo.php) | Meta, Open Graph i dane strukturalne; wyłączają się, gdy działa Rank Math lub Yoast. |
