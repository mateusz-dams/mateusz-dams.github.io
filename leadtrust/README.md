# Leadtrust Group – projekt treningowy

Ćwiczenie z kodowania stron: strona agencji pracy z osobnymi ścieżkami dla pracowników i pracodawców, zakodowana w HTML, CSS i JavaScript na podstawie **profesjonalnego projektu graficznego agencji Ajmer**. Projekt graficzny, treści i zdjęcia nie są moje – moja praca to przeniesienie projektu na działający, responsywny kod.

Autor kodu: Mateusz Dams · [portfolio](https://mateusz-dams.github.io/)

## Zakres ćwiczenia

- **Zakodowane podstrony:** wybór ścieżki, oferta dla firm, outsourcing pracowniczy, oferty pracy, aplikuj, strefa pracownika, social media, o nas, FAQ, kontakt – 10 podstron.
- **Co działa:** przejścia między zakodowanymi podstronami, wygląd formularza aplikacyjnego, układ na telefonie.
- **Poza zakresem ćwiczenia:** wysyłka formularzy, wyszukiwanie, logowanie, przełącznik języka i podstrony, których nie było w projekcie. Po kliknięciu takiego elementu strona pokazuje krótki komunikat, a formularze działają w trybie pokazowym i niczego nie wysyłają.

Kopia ma znacznik `noindex`, żeby nie pojawiała się w wyszukiwarce obok strony firmy.

## Technologie

HTML · CSS (bez frameworka) · JavaScript
