# Austrowaren – projekt treningowy

Ćwiczenie z kodowania stron: strona firmy projektującej systemy odbioru ścinki papieru, tektury i folii, zakodowana w HTML, CSS i JavaScript na podstawie **profesjonalnego projektu graficznego agencji Ajmer**. Projekt graficzny, treści i zdjęcia nie są moje – moja praca to przeniesienie projektu na działający, responsywny kod.

Autor kodu: Mateusz Dams · [portfolio](https://mateusz-dams.github.io/)

## Zakres ćwiczenia

- **Zakodowane podstrony:** strona główna, o nas, oferta, realizacja, kontakt – 5 podstron.
- **Co działa:** menu mobilne, slider na stronie głównej, przejścia między zakodowanymi podstronami.
- **Poza zakresem ćwiczenia:** wysyłka formularzy, wyszukiwanie, logowanie, przełącznik języka i podstrony, których nie było w projekcie. Po kliknięciu takiego elementu strona pokazuje krótki komunikat, a formularze działają w trybie pokazowym i niczego nie wysyłają.

Kopia ma znacznik `noindex`, żeby nie pojawiała się w wyszukiwarce obok strony firmy.

## Technologie

HTML · CSS · JavaScript · jQuery · Slick (slider)
