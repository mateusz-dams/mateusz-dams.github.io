# Staxx Polska – projekt treningowy

Ćwiczenie z kodowania stron: katalog producenta wózków paletowych, zakodowana w HTML, CSS i JavaScript na podstawie **profesjonalnego projektu graficznego agencji Ajmer**. Projekt graficzny, treści i zdjęcia nie są moje – moja praca to przeniesienie projektu na działający, responsywny kod.

Autor kodu: Mateusz Dams · [portfolio](https://mateusz-dams.github.io/)

## Zakres ćwiczenia

- **Zakodowane podstrony:** strona główna, lista produktów, karta produktu, kontakt – 4 podstrony.
- **Co działa:** menu mobilne z kategoriami, rozbudowane menu kategorii na komputerze, przejścia z kategorii do listy produktów.
- **Poza zakresem ćwiczenia:** wysyłka formularzy, wyszukiwanie, logowanie, przełącznik języka i podstrony, których nie było w projekcie. Po kliknięciu takiego elementu strona pokazuje krótki komunikat, a formularze działają w trybie pokazowym i niczego nie wysyłają.

Kopia ma znacznik `noindex`, żeby nie pojawiała się w wyszukiwarce obok strony firmy.

## Technologie

HTML · CSS (bez frameworka) · JavaScript
