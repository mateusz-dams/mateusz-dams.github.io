# Topblind – projekt treningowy

Ćwiczenie z kodowania stron: sklep z plisami i roletami na wymiar, zakodowana w HTML, CSS i JavaScript na podstawie **profesjonalnego projektu graficznego agencji Ajmer**. Projekt graficzny, treści i zdjęcia nie są moje – moja praca to przeniesienie projektu na działający, responsywny kod.

Autor kodu: Mateusz Dams · [portfolio](https://mateusz-dams.github.io/)

## Zakres ćwiczenia

- **Zakodowane podstrony:** strona główna, oferta, karta produktu, blog, 3 wpisy poradnikowe, regulamin, kontakt – 9 podstron.
- **Co działa:** menu mobilne, slider na stronie głównej, galeria i karta produktu, rozwijane sekcje, wszystkie linki prowadzą do zakodowanych podstron.
- **Poza zakresem ćwiczenia:** wysyłka formularzy, wyszukiwanie, logowanie, przełącznik języka i podstrony, których nie było w projekcie. Po kliknięciu takiego elementu strona pokazuje krótki komunikat, a formularze działają w trybie pokazowym i niczego nie wysyłają.

Kopia ma znacznik `noindex`, żeby nie pojawiała się w wyszukiwarce obok strony firmy.

## Technologie

HTML · CSS · JavaScript · jQuery · Slick (slider) · jQuery Accordion
